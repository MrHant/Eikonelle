# Taking Screenshot

Application can take screenshot by pressing specified key combination.
There are different Capture Modes to take a screenshot.
Screenshot is taken using Capture Mode chosen in Settings.

Capture Modes:
 * Full Screen
   * Takes a screenshot of a full primary monitor
 * Region
   * Changes mouse cursor (only for a period of selecting a region)
   * Allows user to drag a region to capture (click, drag, release)
   * Rectangle is displayed while dragging - resembling area which would be captured

Taken screenshot is displayed in a preview window.

Taken screenshot is automatically saved into configured Save Folder.
