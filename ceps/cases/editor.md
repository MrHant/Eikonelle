# Editor

In Preview window there is a menu item - to open Editor.
Editor is opened in a separate window.

Editor includes ability to draw over the screenshot taken, do a highlighting, and draw geometrical shapes.

Drawing is performed by dragging over the screenshot. Geometrical shapes comprise a line, rectangle, and ellipse. The existing drawing is previewed continuously during a drag.

The pen and geometric shapes tools draw an opaque red four-pixel stroke. The highlighter draws a translucent yellow eighteen-pixel stroke. Tool colors and widths are fixed.
