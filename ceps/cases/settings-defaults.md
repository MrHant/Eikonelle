# Settings Defaults

There are default values for all settings.
Default values are applied when no settings are yet configured.
Settings file can either be absent at all, or just individual settings might be missing from file.
Invalid values in settings file - need also to use default value.

Default values are:
 * Capture hotkey: Ctrl+Shift+S
 * Capture Mode: Full Screen
 * UI Mode: System
 * Save Folder: USER_DIR/Documents/Eikonelle
